# Принятые решения (мини-ADR)

Формат: контекст → решение → последствия.

## ADR-0001. Формат ведения решений

- **Контекст:** в задании требуется фиксировать принятые решения в мини-ADR.
- **Решение:** используем этот файл, одна запись на решение, сквозная нумерация.
- **Последствия:** решения видны команде и заказчику, легко сослаться из PR.
