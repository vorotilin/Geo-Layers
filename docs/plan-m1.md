# План M1 — вертикальный срез

Цель этапа (`common-requirements.md` §8): **один сквозной сценарий работает в Docker:
вход → обработка → результат через API, минимальные тесты.**

Сценарий: загрузка GeoJSON-сетки → импорт заданием в воркере → публикация →
**значение в точке** и **тайл PNG** через API.

Основа — `docs/design.md` (§12, §13), ADR-0002…0010, `common-requirements.md` §4–5.
Требование M1 закрыто после шага 9; шаги 10–11 — остальное из M1 по дизайну.

## Упрощения M1 относительно design §13

- **Без S3.** Исходные файлы и массивы значений лежат на общем volume api и
  worker (`DATA_DIR`), за небольшим интерфейсом хранилища. Реализация S3 — на M2
  вместе с загрузкой по ссылке. Причина: MinIO перестал публиковать Docker-образы
  (`minio/minio` удалён с Docker Hub); замену (SeaweedFS или аналог) выбираем на M2
  отдельным ADR.
- **Без Redis.** Он нужен только для rate limit, а rate limit — M2.
- В compose на M1 три сервиса: `api`, `worker`, `postgres` (+ одноразовый `migrate`).

## Этап А. Каркас — чтобы всё сразу жило в Docker

1. **Скелет проекта.** `pyproject.toml` + `uv.lock`, пакет `app/`, конфиг только
   из env (`pydantic-settings`, по `.env.example`), JSON-логи с `X-Request-Id`,
   единый формат ошибок `{error, message, details}`; ruff и pytest.
2. **Docker.** Multi-stage `Dockerfile`, не root, `HEALTHCHECK`; `docker-compose.yml`:
   `api`, `worker` (тот же образ), `postgis 16-3.4`. Ручки `/health`,
   `/ready` (БД + хранилище),
   `/docs` только при `APP_ENV=dev`.
   **Проверка:** `docker compose up` на чистой машине.
3. **CI.** Заменить заглушку на ruff + pytest + gitleaks. Зелёный с первого дня.

## Этап Б. Сам сценарий

4. **Схема БД (Alembic), урезанная:** `token`, `file`, `import`, `dataset`, `grid`,
   `grid_cell`, `layer`, `layer_version`, `job`. Namespace фиксированный `shared`;
   Bearer-токен из `BOOTSTRAP_ADMIN_TOKEN`. Миграции — автоматически при старте.
5. **Очередь заданий (ADR-0003):** `SKIP LOCKED`, `heartbeat_at`, команда `worker`,
   `GET /v1/jobs/{id}`. Тесты сразу: двойной захват, падение посреди задания,
   подбор зависших.
6. **Генератор синтетики** (`tests/synth/`): квадраты CRS84 с другим шагом + ячейки
   в UTM; значение ячейки кодирует её номер, ответ известен заранее. Делаем **до**
   импортёра (design §12).
7. **Импорт.** `POST /v1/files` (multipart) → `DATA_DIR` + sha256. `POST /v1/imports`
   с манифестом (§4) → 202 + `job_id`. Воркер: GeoJSON потоково (`ijson`)
   в подпроцессе с rlimit → распознавание `rectilinear` → `grid_cell` →
   `float32[N]` в `DATA_DIR` → статистика → версия `draft` + отчёт об ошибках.
   Дедупликация sha256 + манифест (ADR-0009). Шаг `inspect` можно отложить —
   в M1 манифест присылает клиент.
8. **Публикация и результат.**
   - `POST …/versions/{v}/publish` — в M1 только смена статуса (пирамида обзоров — M2).
   - `GET /v1/values?lat&lng&layers` — делаем **раньше тайлов**: сценарий замыкается здесь.
   - Тайлы 3857 и 3395: тайл индексов (morecantile + pyproj + `searchsorted`) →
     фиксированная палитра, квантили (стили — M2) → PNG → кэш на диске;
     подпись по префиксу (ADR-0008) + `POST /v1/tiles/sign`.
9. **Сквозной тест** в CI с `docker compose up`: загрузка → импорт → опрос задания →
   публикация → значение (сверка с формулой) → тайл (200, PNG). Тот же скрипт /
   коллекция `.http` — для приёмки заказчиком (`common-requirements.md` §9.2).

## Этап В. Остальное из M1 по дизайну

10. Черновик `openapi.yaml`, README «запуск за 10 минут», CHANGELOG.
11. Минимальная `/ui` (Vue 3 + MapLibre, стадия Node в Dockerfile); **первый замер
    тайлов k6** — проверка главного риска (ADR-0002).

## Минимальные тесты M1

- Юнит: эталонные точки 3857/3395, распознавание `rectilinear` (CRS84 и UTM),
  подпись URL, цикл очереди.
- Тайлы по построению: случайные пиксели против ячейки, найденной shapely.
- Интеграционный: сквозной сценарий из шага 9 — на образце и на синтетике.

## Сознательно не в M1 (→ M2)

Другие форматы и типы сеток, точки/KDE, стили и легенда, обзоры на мелких зумах,
namespace и scopes, callback'и, rate limit и Redis, S3, загрузка по URL (SSRF).
